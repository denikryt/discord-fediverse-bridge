Pinned NodeBB baseline: upstream `v4.16.3`. `src/activitypub/mocks.js::actors.category` produces `Group.id=/category/{cid}`, its `url=/category/{slug}` is **not** its identity, and its actor document advertises `inbox=/category/{cid}/inbox`, `outbox=/category/{cid}/outbox`. `mocks.activities.announce` can contain `object=/post/{pid}`. `src/controllers/activitypub/index.js::getCategoryOutbox` checks `topics:read`, queries `cid:{cid}:pids` and emits `Group` Announce records (sometimes with nested Create), 20 per collection page. An exact root match can supply bounded historical membership evidence, but source semantics alone do not establish its completeness across old remote posts, deletion or arbitrary pagination windows. The JSON in `tests/fixtures/nodebb` is a **synthetic scenario fixture using those verified source fields**, not a captured signed wire transaction or proof of live NodeBB interoperability.
